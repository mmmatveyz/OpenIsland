# AGENTS.md — Инструкция и контекст для ИИ-агентов проекта OpenIsland

Добро пожаловать в проект **OpenIsland**! Этот файл является главным справочником и набором правил для любых ИИ-агентов (Antigravity, Claude, ChatGPT, Cursor, Copilot и др.), работающих с этим репозиторием.

---

## 1. Миссия проекта

**OpenIsland** — это нативное/десктопное приложение для Windows 10/11, объединяющее:
1. **Dynamic Island UI**: плавающий, ненавязчивый адаптивный «островок» вверху экрана с плавной физикой анимаций (Apple-like).
2. **PC Monitor & Control**: пульт управления и мониторинга параметров ПК (CPU, GPU, RAM, сеть, батарея, запущенные dev-процессы, порты, медиа-плеер).
3. **AI Hub (OpenCode)**: быстрый доступ к ИИ прямо из островка, включая поддержку авторизации под учетными записями с активными пользовательскими подписками (**Claude Pro/Team**, **ChatGPT Plus**, **Gemini Advanced**) через защищенные браузерные сессии, а также через прямые API-ключи.

---

## 2. Архитектура и стек технологий

| Компонент | Технология | Обоснование |
| :--- | :--- | :--- |
| **Среда выполнения** | **Node.js (>=20) + Electron** | Полноценный Chromium с доступом к `session.fromPartition` для авторизации в ChatGPT / Claude / Gemini через веб-сессии без блокировок Cloudflare и OAuth. |
| **Сборщик & Frontend** | **Vite + React + TypeScript** | Мгновенный HMR, строгая типизация, высокая скорость разработки. |
| **Стилизация & Анимации** | **TailwindCSS + Framer Motion** | Идеальная пружинная физика (spring physics) для анимации сворачивания/разворачивания островка. |
| **Мониторинг ПК** | **`systeminformation` + Win32 API** | Снятие нагрузки CPU, GPU, RAM, дисков, сетевого трафика и процессов нативно под Windows. |
| **Оконный менеджер** | **Electron BrowserWindow (frameless, transparent, alwaysOnTop)** | Расположение по центру вверху экрана, прозрачность, кликабельные и сквозные зоны (click-through). |

## 4. Правила и соглашения для ИИ-агентов (Guidelines)

### 4.1. Безопасность и хранение данных
- **Никаких открытых токенов и паролей в кодовой базе**: сессии и cookies пользователей должны сохраняться в изолированных зашифрованных хранилищах Chromium (`safeStorage` Electron).
- В `Renderer` процессе **всегда** включена изоляция контекста (`contextIsolation: true`, `nodeIntegration: false`). Все общение с системой происходит строго через `contextBridge` в `preload.ts`.

### 4.2. Производительность (Zero UI Lag)
- Островок находится на экране постоянно — фоновое потребление CPU должно стремиться к 0-1%.
- Опрос метрик ПК (`systeminformation`) должен выполняться в `Main` процессе с адаптивным интервалом:
  - В свернутом состоянии: раз в 2-3 секунды.
  - В развернутом режиме мониторинга: раз в 1 секунду.
  - При бездействии/спящем режиме: замедление или пауза.
- Анимации трансформации размера островка должны выполняться через GPU (transform / scale / Framer Motion layout animations) без дерганий перерисовки окна.

### 4.3. Оформление кода
- Использовать **TypeScript** со строгой типизацией (`strict: true`), избегать `any`.
- Использовать **Zustand** для легкого реактивного стейта.
- Все компоненты должны быть модульными: добавление нового виджета в островок (например, Git status, Docker или Spotify) не должно ломать базовую структуру капсулы.
