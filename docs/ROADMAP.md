# Roadmap проекта OpenIsland

План развития. Отметки отражают фактическое состояние нативной WPF-версии (`desktop/OpenIsland`).

---

## 📌 Фаза 1: Фундамент и островной UI — **готово**
- [x] Высокопроизводительная нативная основа: C# WPF (.NET 8) с пружинными анимациями (Spring physics).
- [x] Нативное окно-оверлей поверх всех окон (`Topmost`, `AllowsTransparency`, `NoResize`, `WS_EX_TOOLWINDOW | NOACTIVATE`).
- [x] Корректные сквозные клики: окно-хост прозрачное, интерактивны только элементы островка.
- [x] Базовые состояния:
  - [x] **Свернутое**: капсула с часами, зарядом, индикаторами.
  - [x] **Компактно-активное**: статус агента OpenCode, медиа, таймер, запись, громкость.
  - [x] **Развернутое**: карточки меню, настроек, плеера, таймера, погоды, OpenCode и др.
  - [x] **Контекстное меню**: правый клик по островку.
- [x] Скрытие в полноэкранных приложениях, удержание поверх окон без кражи фокуса.
- [x] Настройки внешнего вида (масштаб, отступ, стекло, фон, акцент) в реестре.

---

## 📌 Фаза 2: Интеграция с OpenCode — **готово**
- [x] Автоматическое обнаружение демона OpenCode (`opencode service status`, проверка `/api/info`, повторный поиск при смене порта).
- [x] Автоматический пейринг (`opencode pair`) и получение токена без ручного ввода.
- [x] Шифрованное хранение токена через Windows DPAPI (`%LOCALAPPDATA%\OpenIsland\opencode-token.bin`), миграция старого plaintext-файла.
- [x] Нативный клиент `OpenCodeService.cs` (REST + SSE).
- [x] Список сессий и активного статуса (`/api/session`, `/api/session/active`).
- [x] Список моделей и переключение модели сессии (`/api/model`, `/api/session/{id}/model`).
- [x] Отправка промптов/задач агенту из островка (`/api/session/{id}/prompt`).
- [x] Живой стриминг ответа и статуса через SSE (`/api/event`).
- [x] Создание, переключение и удаление сессий из карточки OpenCode.
- [x] Остановка выполнения (`/api/session/{id}/interrupt`).
- [x] Диагностический прогон `--selftest` (сессии, модели, промпт, ответ).

---

## 📌 Фаза 3: Каталог ИИ-экспертов — **снято**
Первоначально планировался каталог ролей-персон (`tools/agency-agents`) с быстрыми чипами в карточке OpenCode. Перед публикацией каталог удалён как чужой артефакт, а кнопки-персоны убраны из UI: задача агенту уходит в сессию как есть, роли задаются промптом. Вместо этого реализован апдейтер через GitHub Releases.

---

## 📌 Фаза 4: Виджеты и системные интеграции — **в работе**
- [x] Медиаплеер: интеграция с системным плеером (GSMTC), обложка, прогресс, перемотка, источник.
- [x] Живой спектр из реального вывода звука (WASAPI loopback).
- [x] Мини-эквалайзер, реагирующий на **любой** системный звук (капсула `View.Sound` без активного трека).
- [x] Таймер, секундомер, будильник.
- [x] Индикаторы громкости, заряда, наушников, сети.
- [x] Автозапуск с Windows.
- [ ] **Мониторинг ПК в WPF**: CPU (общая и по ядрам), RAM, GPU, диск, сеть, температура — с адаптивным интервалом 1–3 с.
- [ ] Список запущенных dev-процессов и занятых локальных портов (Node, Python, Docker, Go).
- [ ] Быстрые действия: буфер обмена, запуск утилит.

> Апстрим-виджеты «Тексты песен», «Запись OBS», «Полка файлов», «Погода» и «QR-код» вырезаны из проекта. Мониторинг ПК на базе `systeminformation` был только в раннем прототипе; в нативной версии этот модуль ещё не реализован.

---

## 📌 Фаза 5: Расширенные возможности OpenCode — **в работе**
- [x] SSE-стриминг событий OpenCode (`/api/event`) с автопереподключением.
- [x] Одобрение и отклонение прав агента прямо с островка (`/api/session/{id}/permission/{requestID}/reply`).
- [x] Показ ошибок выполнения и повторных попыток модели (`session.status` → `retry`).
- [ ] Просмотр диффов изменений (`/api/session/{id}/diff`) с подсветкой и переходом к файлам.
- [ ] История сообщений сессии с прокруткой (сейчас показывается последний ответ).
- [x] Глобальный хоткей **Ctrl+Alt+O** — открыть/свернуть карточку OpenCode из любого приложения.
- [x] Звук завершения задачи — тот же `staplebops-01`, что играет сам OpenCode (MIT).
- [ ] Уведомление Windows (тост) при завершении длинной задачи агента.

---

## 📌 Фаза 6 (Отложено / Future): Авторизация по персональным подпискам
- [ ] Изолированный модуль `AISessionManager` (Claude Pro, ChatGPT Plus, Gemini Advanced) на основе браузерных сессий.
- [ ] Проксирование локальных инструментов в веб-сессию для агентского цикла без API-ключей.
- [ ] Альтернатива: прямое подключение API-ключей провайдеров через настройки OpenCode.

Дизайн и ограничения описаны в [`AI_SESSION_AUTH.md`](./AI_SESSION_AUTH.md). В текущей WPF-версии используется только локальный OpenCode с его собственными провайдерами.

---

## 📌 Фаза 7: Кастомизация и релиз — **готово**
- [x] Настройки внешнего вида: масштаб, отступ, стекло, фон, акцент, вид эквалайзера.
- [x] Автозапуск с Windows.
- [x] Скрипт сборки `scripts/build.ps1` и запуск в один клик (`Запуск_OpenIsland.bat`).
- [x] Логи с ротацией в `%LOCALAPPDATA%\OpenIsland\logs`.
- [x] Portable-сборка: self-contained single-file `OpenIsland.exe` (без установленного .NET), собирается в релизе и проверяется в CI.
- [x] Установщик **Inno Setup**: `installer/OpenIsland.iss`, per-user (`%LOCALAPPDATA%\Programs\OpenIsland`), ярлык в «Пуск», запись в «Программы и компоненты», удаление, опциональные ярлык на рабочем столе и автозапуск. Сборка — `scripts\build.ps1 -Installer`, публикуется как `OpenIslandSetup-<версия>.exe`.
- [x] Автообновление через GitHub Releases: проверка `releases/latest`, скачивание ассета `OpenIsland.exe`, сверка `sha256`-дайджеста, подмена файла и перезапуск.
- [x] Иконка в трее: двойной клик — показать остров, правый клик — «Открыть/Скрыть остров», «Настройки», «Выход».
- [ ] Подпись исполняемого файла — **не планируется** (требует платного сертификата; SmartScreen может предупредить при установке). MSIX без доверенной подписи установить нельзя.
