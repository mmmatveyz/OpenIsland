# Roadmap проекта OpenIsland

План разработки разбит на 5 ключевых фаз от фундамента до полноценного релиза.

---

## 📌 Фаза 1: Фундамент и Островной UI (Foundation & Dynamic Island Core)
- [x] Инициализация проекта: Electron + Vite + React + TypeScript + TailwindCSS.
- [x] Настройка прозрачного безрамочного окна `BrowserWindow` поверх всех окон (`alwaysOnTop`).
- [x] Реализация механизма сквозных кликов (`ignoreMouseEvents` при выходе курсора из активной области островка).
- [x] Базовые состояния островка с пружинными анимациями (Framer Motion):
  - [x] **Свернутое (Compact/Capsule)**: маленькая аккуратная черная «таблетка» по центру экрана.
  - [x] **Компактно-активное (Active/Pill)**: появление мини-иконок и индикаторов CPU/RAM/ИИ.
  - [x] **Развернутое (Expanded Panel)**: всплывающая карточка управления при ховере/клике.

---

## 📌 Фаза 2: Пульт мониторинга ПК (System Hardware Monitor)
- [ ] Интеграция библиотеки `systeminformation` в Main процесс.
- [ ] IPC-канал передачи метрик в реальном времени:
  - Нагрузка и температура процессора (CPU %).
  - Оперативная память (RAM % и ГБ).
  - Нагрузка видеокарты (GPU %).
  - Входящий/исходящий сетевой трафик (KB/s, MB/s).
  - Индикатор батареи для ноутбуков.
- [ ] Виджет мониторинга для свернутого и развернутого состояния островка.
- [ ] Настройка частоты опроса для снижения фонового потребления ресурсов (до < 0.5% CPU).

---

## 📌 Фаза 3: Сессионная авторизация ИИ (AI Hub & Subscription Auth)
- [ ] Разработка модуля `AISessionManager` в Electron Main:
  - Создание изолированных партиций `persist:ai_claude`, `persist:ai_chatgpt`, `persist:ai_gemini`.
  - Модальное окно браузера для разового входа пользователя (Google/Apple SSO/Email).
  - Автоматическое сохранение сессии и cookies в зашифрованном виде (`safeStorage`).
- [ ] UI выбора активного провайдера (Claude, ChatGPT, Gemini, Local Ollama, Custom API).
- [ ] Поле быстрого ввода промпта (Quick Prompt) в островке по горячей клавише (например, `Alt + Space` или клик по острову).
- [ ] Потоковый вывод ответов ИИ (Streaming) прямо в развернутую карточку островка.

---

## 📌 Фаза 4: OpenCode & Dev Tools
- [ ] Детектирование локальных dev-серверов (порты 3000, 5173, 8000, 8080).
- [ ] Интеграция с Git: отображение активной ветки и статуса изменений в свернутом островке.
- [ ] Режим терминального помощника: возможность спросить ИИ команду и скопировать/выполнить её в один клик.
- [ ] Поддержка расширения функционала через локальный WebSocket API.

---

## 📌 Фаза 5: Кастомизация, полировка и релиз
- [ ] Панель настроек: выбор тем (Dark, Light, Windows Mica/Acrylic, Custom Colors).
- [ ] Настройка поведения островка: автоскрытие при полноэкранных играх/видео, выбор монитора.
- [ ] Автозапуск с Windows (Windows Startup Service).
- [ ] Сборка инсталлятора через `electron-builder` (NSIS exe / portable).
- [ ] Автообновление (electron-updater).
