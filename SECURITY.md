# Политика безопасности

## Поддерживаемые версии

Исправления безопасности выпускаются для последнего релиза OpenIsland.

| Версия | Поддержка |
| :--- | :--- |
| 1.x (последний релиз) | ✅ |
| старше 1.x | ❌ |

## Как сообщить об уязвимости

**Не создавайте публичный issue для уязвимостей.**

Используйте приватный канал:

1. **GitHub Private Vulnerability Reporting** — вкладка **Security → Report a vulnerability** в репозитории.
2. Либо напишите владельцу репозитория через профиль GitHub.

Пожалуйста, приложите:

- затронутую версию (`--version` или строка версии в настройках острова);
- версию Windows;
- шаги воспроизведения и, по возможности, минимальный пример;
- оценку влияния (что можно прочитать/изменить/выполнить).

## Что считается уязвимостью

- утечка токена OpenCode или иных секретов (из DPAPI-хранилища, логов, сети);
- выполнение кода или команд по данным из ответов API/страниц;
- подмена обновления: обход проверки `sha256`-дайджеста, загрузка чужого бинарника;
- повышение привилегий, выход за пределы текущего пользователя.

Обычные баги и пожелания — в Issues.

## Что мы делаем

- Подтверждаем получение отчёта.
- Разбираемся и готовим исправление в приватном порядке.
- Публикуем фикс и, при необходимости, уведомление в релизе.

Спасибо, что помогаете сделать проект безопаснее.
